# Project Title: Leetcode Timer

## Description:
Leetcode Timer is a Chrome extension designed to help users track their time and data while practicing coding questions on the website "leetcode.com". This extension includes a timer, pause/resume button, and the ability to download data in CSV format. It aims to improve learning and productivity by providing users with a simple and efficient way to manage their time and progress on the platform.

## Architecture:
The Leetcode Timer extension is built using JavaScript and utilizes the chrome.storage.local API to store and retrieve data. The code is organized into multiple files, with functions for handling data and manipulating storage. The extension also includes a manifest file with permissions for various actions on browser tabs.

## Prerequisites:
- Google Chrome browser
- Access to the "leetcode.com" website

## Installation:
1. Open the Google Chrome browser.
2. Go to the Chrome Web Store and search for "Leetcode Timer".
3. Click on the "Add to Chrome" button to install the extension.
4. Once the installation is complete, the extension will appear in the top right corner of the browser.

## Configuration:
There are no specific environment variables or settings required for the Leetcode Timer extension. However, users can customize the timer settings and data storage options within the extension's options menu.

## Usage:
1. Open the "leetcode.com" website.
2. Click on the Leetcode Timer extension icon in the top right corner of the browser.
3. The timer will automatically start when a coding question is opened on the website.
4. Use the pause/resume button to manage your time while working on the question.
5. To download data in CSV format, click on the "Download Data" button in the extension's options menu.

## API Reference:
The Leetcode Timer extension does not expose any APIs.
